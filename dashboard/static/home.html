System Architecture

Core Engineering Foundations

Autonomous Vision-Language-Action

Unified cognitive reasoning engine. Ingests natural language commands and spatial memory to synthesize metric trajectories, high-precision pick-and-place waypoints, and gesture actions with instant deterministic execution.

3D Semantic Spatial SLAM

Persistent spatial affordance memory tracking entity bounding volumes, contact relationships, grasp clearances, and dynamic tower layer states (Base, Mid, Apex).

Zero-Impulse Kinematics

5-DOF analytical geometric IK with contact stabilization dwell, anti-topple stationary jaw release, and dynamic transit altitude clamping (≤ 1.12m) to prevent toppling during multi-layer stacking.

Tabletop Frontier Exploration

Autonomous multi-view visual scanning across NW, NE, SW, and SE table quadrants at safe hover altitude (0.855m) to resolve occlusions and guarantee 100% table coverage.

60 FPS WebGL Studio

Monochromatic noir Three.js 3D viewport featuring an articulated Panda-style cobot, OrbitControls, studio lighting, glowing TCP trajectory trails, and multi-camera perspectives (Orbit & Top View).

Native ROS 2 Ecosystem

Complete ROS 2 package (vla_robot_arm) with cognitive thought publishers, action plan streams, semantic map nodes, and launch configurations for ROS 2 Humble/Jazzy.

Playground Evaluation Suite

VSArena-aligned benchmarking featuring 18-tick (0.3s) physical stability hold verification, spatial accuracy scoring (70% pos, 30% orientation), closed-loop visual servoing, and joint torque telemetry.
